# 一、面向对象编程

## 1.面向对象的三大特性

### 1.1 封装

- 封装是指将对象的属性和方法封装在一起，对外界隐藏对象的内部实现细节，只提供公共的接口给外部使用。

```python
class Car:
    def __init__(self, make, model):
        self.make = make
        self.model = model

    def start(self):
        print(f"{self.make} {self.model} is starting.")

    def stop(self):
        print(f"{self.make} {self.model} is stopping.")
```
**好处** ：
- 隐藏了对象的内部实现细节，只提供公共的接口给外部使用。
- 提高了代码的可维护性和可扩展性。

**缺点** ： 
- 隐藏了对象的内部实现细节，外部无法直接访问对象的属性和方法。
- 隐藏了对象的内部实现细节，外部无法直接修改对象的属性和方法。

### 1.2 继承

- 继承是指一个类继承另一个类的属性和方法，从而实现代码的复用。
  
```python
class Animal:
      def __init__(self, name):
          self.name = name
      def speak(self):
          print(f"{self.name} is speaking.")
```
**好处** ： 
- 实现了代码的复用，提高了代码的可维护性和可扩展性。
- 实现了代码的复用，提高了代码的可维护性和可扩展性。


### 1.3 多态

- 多态是指同一个接口可以有不同的实现方式，从而实现代码的灵活性和可扩展性。

```python
class Dog(Animal):
    def speak(self):
        print(f"{self.name} is barking.")

class Cat(Animal):
    def speak(self):
        print(f"{self.name} is meowing.")
```
**好处** ： 
- 实现了代码的灵活性和可扩展性，提高了代码的可维护性和可扩展性。    
- 实现了代码的灵活性和可扩展性，提高了代码的可维护性和可扩展性。（一象多用）

## 二、面向对象是什么？
 
- 面向对象是一种编程范式，它将对象作为编程的基本单位，将对象的属性和方法封装在一起，对外界隐藏对象的内部实现细节，只提供公共的接口给外部使用。面向对象编程的主要特点包括封装、继承和多态。面向对象编程的优点包括提高代码的可维护性和可扩展性，提高代码的灵活性和可扩展性，提高代码的可读性和可理解性。面向对象编程的缺点包括隐藏了对象的内部实现
