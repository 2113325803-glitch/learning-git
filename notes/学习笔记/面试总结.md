## 面试-1
```text
面试官问：“介绍一下你最近做的最有代表性的项目？”

你可以自信地说：“我结合自己的化工专业背景，开发了一套化工实验数据管理与预测系统。技术栈是 Python + FastAPI + MySQL + Pandas + Scipy + Pytest。

在这个项目里，我做了严格的分层架构设计，底层用 pymysql 操作数据库；中间层用 Pandas 清洗异常实验数据，并用 Scipy 拟合温度-收率抛物线，预测最优反应温度；上层用 FastAPI 暴露接口。

在质量保障方面，我使用 pytest + requests 编写了接口自动化测试，不仅断言 HTTP 状态码，还直连 MySQL 做数据落库一致性校验。此外，我通过 GitHub Actions 配置了 CI 流水线，每次提交代码都会触发云端自动测试。这个项目让我真正打通了从后端开发到自动化测试的全链路。”

```
