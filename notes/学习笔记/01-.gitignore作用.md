# .gitignore作用
.gitignore 是 Git 的版本忽略配置文件，告诉你 Git 哪些文件/目录不要纳入版本管理（不会被 git add、git commit 上传到远程仓库）

## 规则匹配技巧
1. **通配符**：使用通配符来匹配文件或目录，例如：
  - `*.txt`：匹配所有以 `.txt` 结尾的文件
2. **排除规则**：使用 `!` 符号来排除特定文件或目录，例如：
  - `!README.md`：排除 `README.md` 文件
3. **目录匹配**：使用 `/` 符号来匹配目录，例如：
  - `/logs/`：匹配 `logs` 目录及其所有子目录

1. **查看当前目录下的 .gitignore 文件**：
  ```bash
  git check-ignore -v images/catalyst_comparison.png


```
- 若返回 `!images/catalyst_comparison.png`，则表示该文件被忽略
- 若返回 `images/catalyst_comparison.png`，则表示该文件未被忽略


## ` __file__ == "__main__":`
1.作用：当脚本被直接运行时，执行特定的代码块。
2.应用场景：当你需要在脚本中执行一些特定的操作，而这些操作不需要被其他脚本调用时，可以使用 `if __file__ == "__main__":` 来实现。
3.示例
```python
if __name__ == "__main__":
    print("This script is being run directly.")
    # 在这里执行一些特定的操作
    # 例如：读取文件、执行计算、启动服务等
    # 例如：读取文件
    with open("example.txt", "r") as file:
        content = file.read()
        print(content)
        # 例如：执行计算
        result = 10 + 20
        print("The result is:", result)
        # 例如：启动服务
        # import my_service
        # my_service.start()
```


- `__main__` 是一个特殊的变量，它在 Python 脚本中被定义为 `__main__`，当脚本被直接运行时，`__name__` 的值为 `__main__`，否则为脚本的模块名。


- `__file__` 是一个特殊的变量，它在 Python 脚本中被定义为脚本的文件名，当脚本被直接运行时，`__file__` 的值为脚本的文件名，否则为脚本的模块名。


- `os.path.dirname(__file__)` 是一个函数，它返回脚本的目录名，代表脚本所在的目录，若再一次用 `os.path.dirname(__file__)`，则会返回脚本的父目录名，以此类推。
