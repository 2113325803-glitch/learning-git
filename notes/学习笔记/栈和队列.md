# 栈（Stack）

## 特点

- 后进先出（LIFO）  像一摞盘子，最后放上去的最先拿走
- 最后添加的元素最先被移除
- 最上面的叫栈顶-就是末尾（top），最下面的叫栈底-就是开头（bottom）

## 应用场景

- 括号匹配
- 回文判断
- 递归调用
- 基本数据结构的实现（如栈、队列、树等）

## 实现

### 用 Python 列表直接实现栈
```python
stack = []          # 创建一个空栈

stack.append("A")   # 放 A 进去
stack.append("B")   # 放 B 进去
stack.append("C")   # 放 C 进去

top = stack.pop()   # 拿出最上面的
print(top)          # 输出 C

top = stack.pop()   # 再拿
print(top)          # 输出 B
```
> append() 和 pop() 方法分别用于在栈顶添加元素和移除元素
> 栈封装成类
```python
class Stack:
    def __init__(self):
        self.items = []

```

- len()方法求栈的长度
- is_empty()方法判断栈是否为空
- push(item)方法在栈顶添加元素
- pop()方法移除栈顶元素
- peek()方法查看栈顶元素
- size()方法返回栈的大小

## 队列Queue

### 特点

- 先进先出（FIFO）  像一个排队的人，先排队的人最先拿走
- 最前面的叫队首-就是开头（front），最后面的叫队尾-就是末尾（rear）（有俩个口：一端进-队尾一端出-队头）

### 应用场景

- 任务调度
- 消息队列
- 优先级队列
## 为什么用队列不用普通列表

- 普通列表的 append() 和 pop() 方法在列表的末尾进行操作，效率较低
- 队列的 append() 和 pop() 方法在列表的开头进行操作，效率较高-支持从两端快速添加和删除元素
>模块
```python
from collections import deque
```
### 把队列封装成类
```python
from collections import deque  # 使用 collections 库中的 deque 类来实现队列

class Queue:   # 定义一个队列类
    def __init__(self):   # 初始化一个空队列
        self.items = deque()  # 使用 deque 类来实现队列

    def enqueue(self, x):       # 添加元素到队尾
        self.items.append(x)   #把 x 加到右端，也就是队尾。

    def dequeue(self):     # 从队首移除元素
        if not self.items:    # 如果队列为空，返回 None
            return None       
        return self.items.popleft()     # 从左端移除元素，也就是队首。

    def front(self):
        if not self.items:     # 如果队列为空，返回 None
            return None
        return self.items[0]    # 返回队首元素。

    def is_empty(self): # 判断队列是否为空
        return len(self.items) == 0 # 判断队列是否为空。
        
        
```
## 一句话：栈：只在一端操作，后进先出。Python 用 list，append 进，pop() 出。

## 队列：一端进另一端出，先进先出。Python 用 deque，append 进，popleft() 出。

## 两者操作都是 O(1)，非常快。
