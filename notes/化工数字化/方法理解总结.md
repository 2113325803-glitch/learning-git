## 一，Python 面向对象方法
### 1. `__init__(self, ...)`  构造函数
#### 是什么：创建对象时自动调用的方法
- 为啥要这样写：每创建一个实验记录，需要把外部传入的数据'绑定'到对象身上
```python 
class Experiment:
    def __init__(self, exp_id, temperature, pressure, catalyst, yield_rate, id=None):
        self.id = id                    # 把参数赋给实例属性
        self.exp_id = exp_id
        self.temperature = temperature
        self.pressure = pressure
        self.catalyst = catalyst
        self.yield_rate = yield_rate
```
**核心理解**
- `self = "我自己"`，代表当前创建的这个对象
- `self.xxx = xxx`= "在我身上贴上标签叫xxx,值是xxx" 
- `id=none`=默认参数，可以不传，创建新实验时还没入库的id就是None
  

### 2.`__str__(self)`  魔术方法
#### 是什么：当你 print(对象) 或 str(对象) 时，自动调用。
- 为什么要写：不写的话，print(exp) 输出的是 `<Experiment object at 0x7f...>（内存地址）`，根本看不懂。
  
```python
def __str__(self):
    return f"实验[{self.exp_id}] 温度:{self.temperature}℃ 收率:{self.yield_rate}%"
```

**核心理解**
- 必须 `return`一个字符串，不能 `print`

- 用了 `f"..."`格式化字符串，`{}`里面可以直接放变量


### 3.`.__dict__` 属性字典

#### 是什么：Python自动给每个对象维护的一个字典，里面存着所有实例属性
- 为什么要用：把对象转成`JSON`存文件/传网络时，需要一个字典
  
```python
exp = Experiment("A-001", 150, 2.5, "催化剂A", 88.0)
print(exp.__dict__)  # {'id': None, 'exp_id': 'A-001', 'temperature': 150, ...}
```

**核心理解**
- `exp.name` 和` exp.__dict__["name"] `是等价的

- 这是 Python 对象底层用字典存储属性的证据

- 不需要自己写 `def __dict__`，Python 自动维护
  

## MySQL数据库方法

### 1.`pymysql.connect(...)` 建立连接
#### 是什么：Python 连接 MySQL 数据库的入口。
```Python
conn = pymysql.connect(
    host="localhost",       # 数据库地址
    port=3306,              # 端口
    user="root",            # 用户名
    password="123456",      # 密码
    database="chemical_lab",# 库名
    charset="utf8mb4"       # 字符集（防止中文乱码）
)

```
**核心理解**
- 连接是稀缺资源，用完必须关
- `charset="utf8mb4"` 是中文环境的标配


### 2.`conn.cursor() `创建游标
#### 是什么：游标，就是“用来执行sql的手”
```Python
cursor = conn.cursor()
cursor.execute("SELECT * FROM experiments")
rows = cursor.fetchall()
```
**核心理解**
- 一个连接可以有多个游标

- 用完要 cursor.close()


### 3.`cursor.execute(sql, params)` 执行 SQL
#### 是什么： 把 SQL 语句发给数据库执行。
```Python
# ✅ 推荐：参数化查询，防止 SQL 注入
cursor.execute(
    "INSERT INTO experiments (exp_id, temperature) VALUES (%s, %s)",
    ("A-001", 150.0)
)

# ❌ 不推荐：字符串拼接，有 SQL 注入风险
cursor.execute(f"INSERT INTO experiments VALUES ('{exp_id}', {temp})")

```


**核心理解**

- %s 是占位符，不是 Python 的格式化，是 SQL 的参数化

- 参数化查询防注入，是大厂硬性规范


### 4.`cursor.fetchall() / fetchone()`
#### 是什么：取出查询结果

```pyhton
rows = cursor.fetchall()   # 返回所有行，是元组列表 [(id, name, ...), ...]
row = cursor.fetchone()    # 返回第一行
```

**核心理解**

- 每一行是一个元组，用下标取值（row[0] 是 id）

- 取完后游标就空了，不能再取

### `conn.commit()` 提交事务
#### 是什么：把 INSERT / UPDATE / DELETE 的改动真正写入硬盘。

- 为什么要写：MySQL 默认在“事务”中，不 commit 就相当于草稿，重启就丢。

```python
cursor.execute("DELETE FROM experiments")
cursor.execute("INSERT INTO ...")
conn.commit()   # ⚠️ 必须！否则前面的操作都没生效
```
**核心理解**

- 查询（SELECT）不需要 commit

- 增删改（INSERT / DELETE / UPDATE）必须 commit

- 忘记 commit 是新手最常见的 bug


### `conn.close() / cursor.close()` 释放资源
#### 为什么：连接是稀缺的，不关会导致“连接池满了”，新请求连不上。
```Python
规范写法：

python
cursor.close()
conn.close()
```

## Pandas 方法
### 1.`pd.DataFrame(data)` 创建数据表
#### 是什么：把字典列表转成二维表（DataFrame）。

```python
data = [{"温度": 120, "收率": 65}, {"温度": 140, "收率": 78}]
df = pd.DataFrame(data)
```
**核心理解：**

- 字典的 key 会成为列名

- DataFrame 就像内存里的 Excel 表


### 2. `df["列名"]` 选列
```python
df["温度"]                # 取一列，返回 Series（一维）
df[["温度", "收率"]]      # 取多列，返回 DataFrame
```
